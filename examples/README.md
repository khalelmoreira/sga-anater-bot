# Examples

Place here:

- A sample `.docx` file, with fake data, in the same format as a real
  hand-filled registration (see `docs/mapeamento.md` for the expected
  structure — 10 tables: Entidade executora, Dados da UFPA, Coordenadas,
  Patrimônio, Ações Potenciais, Integrantes, Políticas Públicas, LGPD,
  Indicadores).
- A saved copy (full HTML, `Ctrl+S` -> "Webpage, Complete") of the UFPA
  Registration page from the SGA/ANATER site, to allow inspecting the
  actual field names/ids without needing access to the live system.

No real data (of families, CPFs, etc.) should go into this folder — only
examples with fictitious data, since the project may be version-controlled
in a repository.
